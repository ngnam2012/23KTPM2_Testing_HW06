# EShop API Test Generator Skill (HW06 - Bloom G9.5)

## 1. Overview
This skill provides an automated, deterministic test generator that produces exhaustive test suites for the EShop backend SUT. It automatically synthesizes:
- **Equivalence Partitioning (EP) & Boundary Value Analysis (BVA)** for all input parameters.
- **OWASP API Security Top 10 vectors** (SEC-01 BOLA, SEC-02 Authentication, SEC-03 Broken Access Control / BFLA, SEC-06 SQLi, SEC-07 Sensitive Data Exposure).
- **Order State Machine Transitions** (valid vs invalid state cancellations).
- **Postman Collection v2.1.0** containing Chai BDD assertions, environment variables (`{{baseUrl}}`, `{{studentId}}`), and automated pre-request scripts.

## 2. Usage Instructions

### Run the Generator Script
To generate test cases for all 19 features (FR-01 to FR-19):
```bash
python generator/api_test_agent.py --target-fr ALL --student-id 23127092 --output-collection collections/AutoGenerated_Collection.postman_collection.json
```

To generate test cases for a specific feature (e.g. FR-04, FR-10, FR-15, FR-09):
```bash
python generator/api_test_agent.py --target-fr FR-04 --student-id 23127092 --output-collection collections/FR04_AutoGenerated.postman_collection.json
```

## 3. Architecture & Heuristics
1. **Spec Parser**: Extracts method, path, query parameters, request body schemas, and authentication requirements.
2. **Domain Partition Engine**: Generates valid happy paths, empty string checks, max length boundaries, negative numbers, zero boundaries, and regex validations.
3. **Security Engine**: Injects unauthorized requests (401), invalid tokens (403), privilege escalation probes (403), and SQL injection payloads (`' OR 1=1`).
4. **Anti-Cheat Enforcement**: Always attaches `X-Student-Id: {StudentID}` to 100% of generated requests.

## 4. Execution via Newman
Run the generated collection with HTML Extra reporting:
```bash
newman run collections/AutoGenerated_Collection.postman_collection.json --env-var studentId=23127092 -r cli,htmlextra --reporter-htmlextra-export reports/AutoGenerated_Newman_Report.html
```
